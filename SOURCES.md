## Metodología del comparador

El optimizador no calcula el coste dividiendo simplemente el área necesaria entre el área de un tablero. Intenta colocar las piezas en cada formato comercial, respetando el grosor y el ancho de sierra indicado. Por eso un tablero grande puede necesitar menos unidades y resultar más barato para el proyecto aunque su precio unitario sea mayor.

El desperdicio se calcula como área comprada menos área de las piezas principales. La trasera se excluye del comparador principal cuando tiene otro grosor. El giro de piezas 90° está desactivado por defecto para no ignorar el sentido de veta.

La calidad-precio combina un 55 % de puntuación económica y un 45 % de índice técnico documental. Este último usa únicamente cinco comprobaciones con datos publicados: aptitud para mobiliario, superficie preparada/acabada, origen certificado, bajas emisiones o ausencia de sustancias peligrosas y resistencia/estabilidad declarada. Los datos desconocidos se marcan como tales y no se transforman en un cero ficticio; se exige una cobertura mínima del 60 % para publicar calidad-precio.

El índice técnico no es una certificación de calidad ni un cálculo estructural. No dimensiona carga, flecha, uniones, tornillería o anclaje antivuelco. La comisión de afiliación no interviene en ninguna puntuación ni en el orden del ranking.
